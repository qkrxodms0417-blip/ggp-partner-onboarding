글로벌 광고주 보안 실사(DDQ)

글로벌 기업 광고주는 전환 스크립트 설치나 광고주센터 사용 전에 벤더 보안 실사(DDQ · Whistic · 보안 체크리스트)를 요구하는 경우가 많습니다. 자주 나오는 질문과 네이버의 표준 답변 방향을 정리합니다.

목차

  • SECTION 1. 언제 필요한가?
  • SECTION 2. 자주 나오는 질문과 표준 답변 방향
  • SECTION 3. 진행이 늦어질 때

1 언제 필요한가?

  • 광고주가 네이버 전환 스크립트(wcslog.js) 설치 전에 Infosec 승인을 요구할 때
  • 광고주 구매·조달 부서가 네이버를 신규 벤더로 등록하면서 DDQ / Vendor intake form을 보낼 때
  • Whistic 등 보안 실사 포털 링크가 전달될 때
진행 원칙: 광고주로부터 실사 요청을 받으면 질문지·포털 링크·마감일을 담당 AM에게 바로 전달하세요. 답변은 네이버 보안·개인정보 조직의 확인을 거쳐 네이버 명의로 제출됩니다. 파트너사가 임의로 답변을 작성해 제출하지 않도록 주의해 주세요.

2 자주 나오는 질문과 표준 답변 방향

질문답변 방향
네이버 소프트웨어를 광고주 환경에 설치하나요?아니요. 광고주 사이트에는 client-side JavaScript 태그 <script src="//wcs.naver.net/wcslog.js">만 삽입됩니다. 캠페인 관리·리포트는 웹 포털 ads.naver.com에서 이뤄집니다.
아키텍처 / 데이터 플로우 다이어그램을 제출해 주세요광고주 환경에 배포·호스팅되는 네이버 소프트웨어가 없으므로 해당 없음(Not applicable).
어떤 데이터가 수집되나요?전환 태그 이벤트: URL, HTTP referrer, 시간, 쿠키, 브라우저 환경 정보, IP(TCP/IP 통신상 자동). 쿠키 ID는 기기·브라우저별 무작위 생성 값이며 회원정보와 연결되지 않습니다. 이름·이메일·전화번호 등 직접 식별 정보는 수집하지 않습니다.
데이터 보관 기간은?리포팅·전환 측정 데이터 7일 / 타기팅 목적 데이터는 광고주 설정 기간(1~180일, 최대 180일 후 삭제) / 재해복구 백업 최대 1년 6개월 후 삭제.
데이터 저장 위치는?대한민국 내 네이버 데이터센터. 광고주가 저장 위치를 선택·제한하는 기능은 제공하지 않습니다.
ISO 27001 SoA 전문을 주세요SoA 전문은 기밀로 제공 불가. ISO/IEC 27001 표준에 따른 통제를 적용하고 있다는 수준으로 회신합니다.
SOC 2 보고서가 있나요?광고 서비스 범위의 SOC 2 보고서는 현재 없습니다. 전사 SOC 3 및 ISO 27001 인증으로 답변합니다.
DPA(Data Processing Agreement)를 체결할 수 있나요?원칙적으로 개별 DPA는 체결하지 않습니다. 전환 태그는 모든 광고주에게 제공되는 공통 광고 서비스로, 네이버가 특정 광고주의 수탁자로 데이터를 처리하는 구조가 아니기 때문입니다. 근거: 광고주센터 운영정책 제11조, 네이버 광고 이용약관.
⚠️ 광고주마다 개인정보 분류 기준이 다릅니다 (예: IP·쿠키 ID를 개인정보로 분류하는 광고주). 이런 경우 답변이 달라질 수 있으므로 반드시 담당 AM을 통해 네이버의 최신 답변을 확인하세요.

3 진행이 늦어질 때

  • 일부 문항은 네이버 내부 여러 조직의 확인이 필요해 시간이 걸릴 수 있습니다. 마감일이 있으면 요청 단계에서 함께 알려 주세요.
  • 광고주가 진행 상황을 문의하면 완료 문항 수 / 전체 문항 수와 예상 완료 시점을 공유합니다 (중간 공유 템플릿).
  • 실사 포털 접속 오류가 나면, 상대사가 포털 측에 티켓을 올리는 동안 요청 Excel 양식으로 먼저 작성해 메일로 송부하는 방식으로 지연을 막을 수 있습니다.
