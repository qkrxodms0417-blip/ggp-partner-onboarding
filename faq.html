자주 묻는 질문

GGP 파트너사가 온보딩·운영 중 가장 자주 묻는 질문을 주제별로 모았습니다. 질문을 누르면 답변이 열리고, 상세 페이지로 바로 이동할 수 있습니다.

1 GGP 프로그램

기존에 운영하던 해외 광고주도 추가 수수료·비즈쿠폰 대상인가요?
아니요. 담당 AM과 협의된 ‘신규 해외 광고주’만 대상입니다. 2025년 네이버 광고 집행 이력이 있는 광고주는 제외되며, 이력의 범위·시점에 따라 개별 검토는 가능합니다. → 신규 해외 광고주 정의

여러 국가의 광고주를 대상으로 해도 되나요?
네. 특정 국가·권역에 한정되지 않으며 복수 국가·글로벌 단위 제안도 가능합니다.

광고주 3자 미팅 지원 기준이 있나요?
정해진 기준은 없고 브랜드 인지도·예산·성장 가능성을 고려해 결정합니다. 담당 AM과 조율해 주세요.

네이버가 연결해 주는 광고주는 어떻게 모집되나요?
네이버쇼핑 입점 해외 셀러, 3rd Party 솔루션 인입 광고주, 네이버 자체 채널로 문의한 광고주 중 대행사 연결을 원하는 광고주입니다. 광고주가 GGP 중 한 곳을 자유롭게 선택합니다.

GGP 관련 문의는 파트너사지원으로 하면 되나요?
아니요. 파트너사지원은 해외 광고주 일반(계정·운영) 문의 창구이고, GGP 프로그램·정산·광고주 연결은 담당 AM 또는 dl_adpartner_global@navercorp.com로 문의합니다. → 문의 채널

2 계약 · 셋업

계약서를 종이로 받을 수 있나요?
아니요. 해외 파트너사도 PATH 전자서명으로 체결합니다. PATH는 영문·중문(간체/번체)을 지원합니다. → 계약 체결

파일럿 참여 확인서를 다시 받을 수 있나요?
네. 법인 정식 명칭과 필요한 유효기간을 담당 AM에게 알려 주세요. 확인서는 참여 사실만 확인하며 공식 대행사 인증이 아닙니다. → 파일럿 참여 확인서

해외에서 광고 계정 접속이 자꾸 차단돼요.
사업장 고정 IP를 등록하세요. 현지 통신사가 발급한 사업장 IP 확인서가 필요하며 클라우드·서버 IP는 인정되지 않습니다. → IP 등록

공식 대행사가 아니어도 광고 API를 쓸 수 있나요?
원칙적으로 공식 대행사에 한해 발급하지만, 파일럿 등 사유로 예외 발급될 수 있습니다. 담당 AM에게 요청하세요.

3 광고주 계정

광고주가 네이버 ID 인증 문자를 못 받아요.
Help Center Account Verification Guide로 인증 횟수 초과·스팸 차단을 확인하고, 그래도 안 되면 Help Center Inquiry Form(한국 번호 불필요)에 스크린샷과 함께 접수합니다. 네이버 광고 담당자가 ID 제한을 직접 풀 수는 없습니다. → ID 가입 · 인증

해외 계정을 나중에 국내 계정으로 바꿀 수 있나요?
불가합니다. 한국 법인을 등록하면 기존 해외 계정은 탈퇴하고 한국 법인 명의로 국내 계정을 새로 만들어야 합니다. → 계정 유형

본사 사업자등록증을 낼 수 없는 광고주는요?
사업자 정상 등록·운영을 확인할 수 있는 대체 서류(양식 자유), 그마저 어려우면 ‘라이선스 외부 공개 불가’ 확인서·메일 증빙으로 대체할 수 있습니다. → 사업자 서류

한국 사업자번호로 만든 해외 광고주 계정도 GGP 대상인가요?
네. 광고주 성격이 해외 광고주라면 인정되며, 파트너사로 매핑하면 파트너사 명의로 세금계산서가 발행됩니다(위임 설정 필요).

광고주가 DPA 체결이나 SOC 2 보고서를 요구해요.
질문지를 담당 AM에게 전달해 주세요. 원칙적으로 개별 DPA는 체결하지 않으며, 광고 서비스 범위의 SOC 2 보고서는 없어 전사 SOC 3·ISO 27001로 답변합니다. → 보안 실사

4 정산 · 결제

추가 수수료 10%는 모든 상품에 붙나요?
아니요. 총 수수료는 25%를 넘을 수 없어, 기본 수수료가 25%인 NOSP 상품(브랜드검색 프리미엄형·스페셜DA 등) 집행분에는 추가 수수료가 지급되지 않습니다. → 인센티브 기준

정산금액 확인 메일은 언제까지 회신해야 하나요?
내부 지급 프로세스를 위해 받은 당일 중 회신해 주세요. → 월간 사이클

정산에서 광고주가 누락됐어요.
계정 ID와 금액 근거를 담당 AM에게 회신하면 익월 정산에 반영됩니다. 정산 매칭은 광고주명이 아니라 계정 ID 기준이므로 리스트에 항상 계정 ID를 적어 주세요.

해외 파트너사는 세금계산서를 발행해야 하나요?
국내 사업장이 없는 해외 파트너사는 세금계산서·원천징수 대상이 아니며, 인보이스로 정산합니다. 인보이스는 익월 4~6일에 송부합니다. → 외화 지급

해외 광고주가 원화로 내면 VAT 10%는 손해인가요?
원화 + 세금계산서 위임 구조라면 세금계산서를 받은 국내 파트너사가 매입세액 공제로 회수할 수 있습니다. 외화로 직접 충전하면 영세율이 적용됩니다. → 결제 구조

비즈머니 환불은 어떻게 하나요?
5개 필수 항목을 담은 확약서를 파트너사지원으로 접수하면 내부 검토 후 결정됩니다. 환불 계좌는 법인 명의로 한정됩니다. → 비즈머니 환불

5 상품 · 운영

대행사도 쇼케이스 EAST를 판매할 수 있나요?
네. 2025년 7월 통합대행권 변경 이후 가능합니다. 다만 부킹은 네이버가 처리하므로 일정·유형·캠페인 정보를 담당 AM에게 먼저 공유해 주세요. → 부킹 절차

선점유 후 바로 캠페인에 구좌가 들어오나요?
아니요. 구좌 이관은 선점유 완료 기준 차주 화요일 이후 가능합니다.

NOSP에서 상품 인벤토리가 조회되지 않아요.
광고주·대행사 권한은 신제품검색·서칭뷰·브랜드검색 외 상품의 조회·직접 구매가 제한됩니다. NOSP 업무요청게시판으로 선입금 제안을 요청하세요. → 권한 범위

해외법인이라 NOSP 소속회사가 없어요.
dl_refund@gwebscorp.com으로 사업자등록증 사본과 재무 담당자 정보(이름·휴대폰·이메일)를 보내면 수기 등록 후 회신됩니다. → NOSP 가입

Shopify 상품 피드를 네이버쇼핑에 그대로 쓸 수 있나요?
불가합니다. 네이버 EP 가이드(영문)에 맞춰 새로 생성해야 하며 자동 변환 솔루션은 없습니다. → EP 준비

중국 숏드라마 플랫폼도 바로 광고할 수 있나요?
영상물등급위원회 등급 분류와 광고 선전물 사전 심의 요건을 먼저 충족해야 합니다. → 사전 요건
