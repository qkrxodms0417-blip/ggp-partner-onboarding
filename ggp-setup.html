2 계약 체결

계약서 구성

2026년 7월 1일부로 모든 파트너사 계약은 「네이버 광고 파트너사 통합 계약서」 하나로 통일했습니다. 해외 파트너사·파일럿 파트너사도 통합 계약서를 사용합니다.

No.부속 서류비고
1파트너사 수수료 부속합의서수수료율·지급 기준
2광고 파트너사 SLA서비스 수준 합의
3공정경쟁 협약서
4윤리실천 협약서
5개인정보의 처리와 보호에 관한 합의서 (제3자 제공)광고주 정보 처리 관련
💡 후불 결제, 신용카드 검수 등은 계약서와 별도로 이메일로 합의해야 적용됩니다. 해외 파일럿에는 후불·보장형 부속합의서가 적용되지 않습니다.

PATH 전자서명

  • 계약은 종이 계약서나 도장 없이 PATH 전자계약 시스템으로 체결합니다 (해외 파트너사 동일).
  • PATH는 영문 · 중문(간체/번체)을 지원합니다.
  • 네이버 내부 결재가 끝나면 서명 요청 메일이 발송되며, 수신 메일에서 바로 서명할 수 있습니다.
  • PATH 계정·로그인 등 시스템 이슈: partner_system@navercorp.com

3 파일럿 참여 확인서

해외 파일럿 파트너사가 자국 광고주와의 계약을 위해 네이버 파트너 참여 사실 증빙이 필요한 경우, 영문 Confirmation Letter(파일럿 참여 확인서)를 발급받을 수 있습니다.

요청 시 전달할 정보설명
Full legal entity name확인서에 기재될 법인 정식 명칭 (예: ○○ Co., Limited)
필요 유효기간분기 / 반기 / 연간 단위로 요청 (현재 최대 2026-12-31까지)
용도광고주 계약 증빙 등 사용 목적
⚠️ 확인서는 파일럿 참여 사실만 확인하는 문서이며, 공식 대행사 인증·독점 권한 부여를 의미하지 않습니다. 광고주에게 ‘네이버 공식 대행사’로 소개하지 않도록 주의해 주세요.

파일럿 → 공식 파트너 전환

해외 대행사 파일럿은 보통 3~6개월 테스트로 운영되며, 기간 내 목표(매출·조건)를 달성하면 공식 파트너사 전환을 심사합니다. 전환 전까지는 광고주에게 ‘파일럿 프로그램 참여사’임을 명확히 커뮤니케이션해야 합니다.

4 접속 환경 · IP 등록

해외에서 VPN·해외 IP로 네이버 광고 계정에 접속하면 ‘비정상 로그인’으로 판단되어 접속이 차단되는 경우가 있습니다. 운영 중 차단을 줄이려면 파트너사 사업장 고정 IP를 등록하세요.

구분인정 여부
현지 통신사(ISP)가 발급한 사업장 IP 확인서 (예: China Telecom, China Unicom 등)✅ 인정
클라우드 · 서버 · 호스팅 IP 증명서 (예: 클라우드 서비스 IP)❌ 불인정
💡 사업장 IP 확인서는 담당 AM에게 전달해 주세요.

5 NOSP · API 권한

  • 보장형 DA(NOSP) 상품을 판매하려면 NOSP 회원가입과 소속회사 등록이 필요합니다. → NOSP · 보장형 상품 부킹
  • 네이버 광고 API 권한은 원칙적으로 공식 대행사에만 발급하지만, 파일럿 기간 지원을 위해 예외 발급될 수 있습니다. 필요 시 담당 AM에게 요청하세요.
  • API 활용 가이드: naver-ad-api.github.io/developers · 검색광고 API 문서
