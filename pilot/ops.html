광고 운영

네이버 광고의 기본 구조를 살펴본 뒤, 광고주 계정 연결과 비즈채널 검수 절차를 안내합니다.

네이버 광고 이해하기

네이버 광고주센터(ads.naver.com)는 네이버 ID로 로그인합니다. 파트너사 팀원과 광고주 담당자 모두 각자의 네이버 ID가 필요합니다.

관리 계정과 광고 계정

광고 계정은 광고주가 광고를 만들고 광고비를 사용하는 계정입니다. 관리 계정은 파트너사가 여러 광고주의 광고 계정을 연결해 한곳에서 운영할 때 사용합니다.

광고는 어떤 단계로 만드나요?

검색광고와 성과형 디스플레이 광고 모두 캠페인 → 광고그룹 → 소재 순서로 설정합니다. 비즈채널은 광고를 클릭했을 때 연결되는 웹사이트 등을 뜻하며, 네이버 검수를 통과해야 광고를 집행할 수 있습니다.

검색광고

  1. 캠페인광고 목적과 예산 (예: 사이트 유입, 쇼핑)
  2. 광고그룹입찰가, 연결할 사이트(비즈채널), 노출 대상
  3. 키워드 · 소재어떤 검색어에, 어떤 문구로 보일지

성과형 디스플레이 광고

  1. 캠페인광고 목적 (예: 웹사이트 전환, 앱 설치)
  2. 광고그룹타겟, 입찰 방식, 예산, 노출 위치, 일정
  3. 소재실제로 보이는 이미지 · 동영상

A. 광고주 계정 만들고 대행권 연결하기

  1. 1광고주 가입네이버 ID로 광고주센터 가입
  2. 2해외 광고주 계정 생성광고 계정 ID 발급
  3. 3파트너사 연결 요청관리 계정에서 연동 · 대행권 요청
  4. 4광고주 승인대행권 이관 완료
  1. 1광고주가 광고주센터에 가입

    광고주 담당자가 ads.naver.com의 ‘회원가입’에서 ‘네이버 ID로 광고 시작하기’를 누르고 로그인합니다.

  2. 2해외 광고주 계정 만들기

    광고 계정 생성 화면에서 ‘해외 광고주’ 탭을 선택합니다. 회사 정보와 광고 계정 이름을 입력한 뒤 ‘광고 계정 생성 완료’를 누릅니다.

  3. 3광고 계정 ID 확인

    생성한 계정의 설정 › 광고 계정 정보에서 광고 계정 ID와 계정 유형(해외 광고주)을 확인할 수 있습니다. 광고 계정 ID를 파트너사에 전달해 주세요.

  4. 4파트너사가 연동 요청

    파트너사 관리 계정 › 설정 › 권한 관리 › 광고 계정 연동에서 광고 계정 ID를 입력해 연동을 요청합니다. 요청 현황은 ‘연동 요청 중인 광고 계정’에서 확인할 수 있습니다.

  5. 5파트너사가 대행권 이관 요청

    관리 계정 › 영업 관리 › 대행권 이관 관리에서 광고 계정을 선택하고 대행권 이관을 요청합니다. 최초 요청 시에는 계정 책임자가 ‘대행권 이관 동의’를 해야 합니다.

  6. 6광고주가 승인

    광고주가 광고 계정 › 설정 › 권한 관리에서 관리 계정 연동 및 대행권 이관 요청을 승인하면 즉시 반영됩니다. 밤 11시부터 새벽 1시까지는 승인할 수 없습니다.

  7. 7연결 완료 확인

    ‘대행권 이관 중입니다.’라는 문구와 파트너사 정보가 표시되면 연결이 완료된 것입니다.

B. 비즈채널 등록하고 검수 통과하기

  1. 1비즈머니 충전0원이면 검수 시작 안 됨
  2. 2비즈채널 생성웹사이트 주소 등록
  3. 3네이버 검수영업일 3~5일
  4. 4결과 확인보류 시 수정 후 재검토
  1. 1비즈채널 만들기

    검색광고 › 구성요소 관리 › 비즈채널에서 ‘비즈채널 생성’을 누릅니다. ‘웹사이트’를 선택한 뒤 이름과 주소를 입력해 주세요. 주소에는 브랜드 대표 사이트를 등록합니다.

  2. 2검수 결과 확인

    비즈채널 목록의 ‘상태’ 열에서 결과를 확인합니다. ‘노출제한’을 누르면 제한 사유와 검수자 의견을 볼 수 있습니다.

  3. 3서류 미리 올리기

    해외 사업자등록증 등 검수에 필요한 서류는 도구 › 서류 관리 › ‘서류등록’에 미리 등록해 두면 재검토에 도움이 됩니다.

  4. 4운영자와 직접 확인

    보류 사유를 확인하거나 추가 문의가 필요하면 관리 계정 오른쪽 위 ‘파트너사 요청’을 이용해 주세요. 답변은 댓글로 확인할 수 있습니다.

해외 광고주는 사이트 하단의 회사 정보, 해외 사업자등록증, 해외 거래처 등록용 Registration Form 등을 요청받는 경우가 많습니다. 게임 광고는 국내 등급분류 관련 증빙이 필요할 수 있으니 함께 준비해 주세요.
