파트너사 등록

계약을 마치면 파트너사 정보를 등록합니다. 네이버 심사가 완료되면 파트너사 관리 계정을 사용할 수 있고, 광고주 계정도 연결할 수 있습니다.

  1. 1등록 양식 받기계약 후 파트너사지원이 발송
  2. 2서류 제출회사 · 계좌 · IP 서류
  3. 3네이버 심사서류 확인
  4. 4관리 계정 승인광고주 계정 연결 가능

등록이 진행되는 동안 팀원들은 각자 네이버 ID를 만들어 주세요. 기존 파일럿 사례에서는 서류 제출부터 승인까지 약 2주가 걸렸습니다.

이 단계에서 막히면

등록 서류파트너사지원 agency_cs@navercorp.com
네이버 ID 로그인 제한담당 AM (참조 dl_adpartner_global@navercorp.com)

1. 파트너사 등록 서류 제출

계약이 끝나면 파트너사지원(agency_cs@navercorp.com)에서 등록 양식을 메일로 보내드립니다. 안내에 따라 아래 서류를 준비해 회신해 주세요.

  • 해외 사업자등록증유효 기간이 남은 최신본
  • 계좌 증빙 서류수수료를 받을 해외 은행 계좌 확인서
  • Registration Form법인 · 담당자 · 은행 정보와 서명이 담긴 영문 양식
  • 개인정보 수집 · 이용 안내내용을 확인하고 회신
  • IP 등록 확인서현지 통신사가 발급한 사무실 고정 IP 확인 문서
  • 담당자 정보정보 등록 엑셀, 파트너사 담당자(대표 · 실무 · 계약 · 정산) 목록
IP 확인서에는 통신사 직인, 사무실 주소, 고정 공인 IP가 포함되어 있어야 합니다. 도메인 증명서, IP 조회 사이트 화면 캡처, 클라우드 서버 주소 증명은 인정되지 않습니다.

2. 팀원 네이버 ID 만들기

광고를 운영할 팀원은 각자 네이버 ID가 필요합니다. 네이버 회원 가입(영문) 페이지에서 약관에 동의하고 이름 · 생년월일(여권 정보와 동일), 휴대폰 인증, 아이디 · 비밀번호 설정 순서로 진행해 주세요. 가입에는 1인당 약 10분이 걸립니다. VPN은 끄고, 팀원마다 본인 계정을 직접 만들어 주세요.

3. 로그인이 막히면 화이트리스팅 요청

아래와 같은 경우에는 로그인이 제한될 수 있습니다. 제한된 네이버 ID와 오류 메시지를 정리해 담당 AM에게 해제(화이트리스트 등록)를 요청해 주세요.

  • 가입 직후 ‘안전하지 않은 환경’ 또는 ‘비정상 가입’ 안내가 뜨는 경우
  • VPN이나 해외 회선으로 가입해 계정이 제한된 경우
  • 같은 사무실에서 여러 ID를 짧은 시간에 만든 경우
