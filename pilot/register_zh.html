合作伙伴注册

完成合同后登记合作伙伴信息。
NAVER审核完成后即可使用合作伙伴 管理账户并关联广告主账户。

  1. 1提交注册材料回复合作伙伴支持团队的表格
  2. 2创建团队成员NAVER ID每人1个账号，约10分钟
咨询注册材料 合作伙伴支持团队 partnersupport@naver.com

1. 提交注册材料

合同阶段完成后，合作伙伴支持团队（partnersupport@naver.com）将通过邮件发送注册表格。
提前准备以下材料回复合作伙伴支持团队，经NAVER审核后将最终批准 管理账户。

注意从提交材料到获批约需2周

需提前准备的材料

  • 海外营业执照仍在有效期内的最新版本
  • 账户证明材料收取佣金的海外银行账户证明
  • Registration Form包含法人 · 负责人 · 银行信息及签名的英文表格
  • 个人信息收集 · 使用告知 NAVER提供NAVER发送的英文告知书（说明收集项目 · 目的 · 保存期限）。
    合作伙伴无需另行制作，确认内容后回复即可
  • IP登记确认书当地运营商出具的办公室固定IP确认文件 （最近一个月内开具）
  • 负责人信息代表 · 实务 · 合同 · 结算业务、服务广场（NSF）、客服中心转接联系电话、佣金税务发票接收 负责人名单

准备 IP 登记证明

IP 登记需在开始广告运营前完成，请准备包含以下内容的文件。

  • 由当地运营商等 IP 提供机构签发的文件
  • 同时注明固定 IP 地址及该 IP 安装地点（办公室地址）的文件
  • 如有多个实际运营广告的办公室，需按办公室分别提交

注意域名注册证明、云服务租用 IP 的证明、IP 查询网站截图均不予认可

签约法人所在地与实际运营办公室不同时

即使签约法人的注册所在地与实际运营广告的办公室位置不同，也可以按实际办公室使用的 IP 进行登记，此时需一并提交以下 2 项。
NAVER 审核后将进行 IP 登记。

  • 简要说明实际运营办公室与签约法人所在地不同的原因（邮件或文件）
  • 各实际运营办公室的 IP 证明

2. 创建团队成员NAVER ID

负责运营广告的团队成员各自需要NAVER ID。
建议在注册材料审核期间提前创建。

NAVER ID创建方法

  1. 1同意条款

    NAVER会员注册（英文） 页面同意必选条款后点击“Confirm”

  2. 2填写姓名 · 出生日期

    依次填写姓名、出生日期、性别。
    姓名 · 出生日期须与护照信息一致

  3. 3手机验证

    选择国家代码后输入手机号，输入通过“Send Code”收到的验证码。
    非本人名下号码也可验证

  4. 4设置账号 · 密码

    账号为5~20位英文小写字母 · 数字 · 特殊字符（-、_），密码为8~16位英文大小写字母 · 数字 · 特殊字符。
    出现“Welcome!”页面即注册完成

注意关闭VPN，在办公室固定网络下注册
每位成员亲自创建1个本人ID，禁止短时间内批量创建多个ID
同一手机号最多可注册3个账号

创建合作伙伴代表管理账户 · 申请正式合作伙伴

创建团队成员 NAVER ID 后，在广告主中心创建合作伙伴代表管理账户并申请正式合作伙伴。
按注册会员 → 创建管理账户 → 申请正式合作伙伴 → 审核 → 批准的顺序进行。

  1. 1创建管理账户

    在广告主中心 › 账户管理 › 管理账户中点击“创建管理账户”，输入管理账户名称。

  2. 2登记合作伙伴付款信息

    在管理账户 › 设置 › 付款管理中点击“登记合作伙伴付款信息”，上传企业信息和企业注册证、税务发票接收信息和负责人在职证明。
    注意付款信息登记 · 申请仅可在代表管理账户中进行，在子管理账户中申请将被驳回

  3. 3NAVER 审核 · 批准

    NAVER 将审核登记的代理商信息，最长可能需要 3 个工作日。
    结果将通过申请会员的邮箱 · 短信通知，批准后代表管理账户即完成，可管理代理佣金结算和代理权设置。

登记付款信息时的填写方法

  • 企业注册号：海外企业没有韩国企业注册号，请以虚拟注册号（999-99-99999）登记
  • 地址：选择 NAVER 地址后，在详细地址中填写实际海外地址信息

可选申请解除登录限制咨询NAVER ID登录限制 NAVER 会员信息客服中心

以下情况可能导致登录受限。 登录限制解除（白名单（解除登录限制））请直接联系 NAVER 会员信息客服中心。

  • 注册后立即出现“不安全环境”或“异常注册”提示的情况
  • 使用VPN或海外网络注册导致账号受限的情况
  • 同一办公室短时间内创建多个ID的情况
  • 登录限制解除申请： NAVER 客服中心帮助
  • NAVER 团体 ID 解除申请： NAVER 客服中心帮助
