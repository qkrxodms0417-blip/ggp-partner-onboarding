정산

정산은 광고비 충전, 광고 집행, 수수료 정산 순서로 진행. 광고비는 미리 충전해 사용하고, 파트너사 수수료는 다음 달에 인보이스를 제출해 지급

  1. 1광고비 충전광고 계정 비즈머니에 미리
  2. 2광고 집행쓴 만큼 비즈머니에서 차감
  3. 3수수료 정산다음 달 인보이스 제출 · 외화 지급

세금계산서와 인보이스

국내 광고주와 파트너사는 세금계산서를 사용하지만, 해외 광고주 계정과 해외 파트너사는 부가세 없이 처리되어 세금계산서 대신 인보이스 사용

세금계산서인보이스
사용 대상국내 광고주 · 국내 파트너사해외 광고주 계정 · 해외 파트너사 (파일럿)
광고비네이버가 광고주에게 매달 발행외화 송금 충전 시 네이버가 충전용 인보이스 발행
파트너사 수수료네이버가 대신 발행(역발행)파트너사가 수수료 인보이스를 작성해 네이버에 제출
부가세있음없음 (해외 광고주 계정은 외화 계정으로 부가세 없이 과금)

1. 광고비 충전

광고비는 해외 카드 또는 외화 송금으로 비즈머니에 충전. 충전 전에 해당 광고 계정의 대행권이 파트너사로 이관되었는지 확인

방법충전 절차반영 시점
해외 카드광고 계정 › 결제 › 비즈머니 관리 › 충전하기에서 해외카드를 고르고 결제 (Visa, Master, JCB 인증 서비스 가입 카드)즉시
외화 송금파트너사지원에 인보이스 요청 → 인보이스의 우리은행 외화 가상계좌로 같은 통화 · 같은 금액 송금 → 늦어지면 NSF에 입금 확인 요청보통 2주, 길게는 4주
  1. 1비즈머니 관리에서 충전

    결제 › 비즈머니 관리에서 ‘충전하기’를 눌러 충전. 외화로 충전해도 잔액은 원화로 표시

  2. 2입금 계좌 확인

    외화 송금 계좌는 결제 › 결제 설정의 입금 계좌에서도 확인 가능. 광고 계정마다 계좌번호가 달라 반드시 해당 계정 인보이스에 기재된 번호 사용

  • 송금 시 받는 사람 이름은 인보이스에 기재된 ‘NAVER(인보이스 번호)’ 그대로 입력
  • 주의원화로 환전해 송금하면 충전 불가
  • 지원 통화: USD, SGD, EUR, GBP, JPY, CNY, HKD, AUD, CAD
  • 환불은 광고주에게만 가능하므로 예상 사용 금액에 맞춰 나눠 충전 권장

2. 광고 집행

광고가 노출되거나 클릭되면 발생한 광고비가 비즈머니에서 차감. 주의잔액이 0원이 되면 광고가 중단되고 검수도 진행되지 않으므로 충전 내역과 잔액 수시 확인

  1. 1충전 · 소진 내역 확인

    결제 › 비즈머니 관리의 ‘충전 내역’과 ‘소진 내역’ 탭에서 기간별 사용 내역 확인

3. 수수료 정산

시점담당할 일
다음 달 첫 영업일파트너사관리 계정 › 결제 › 월별 정산서에서 지난달 수수료 확인. 금액 문의는 4영업일 안에
다음 달 4~6일파트너사수수료 인보이스를 파트너사지원(agency_cs@navercorp.com)에 메일로 제출
제출 직후네이버정산서 금액과 인보이스 금액 대조. 다르면 수정 요청
다음 달 15일 무렵네이버등록된 해외 계좌로 외화 송금. 최대 3일 지연 가능
  1. 1월별 정산서 확인

    관리 계정 › 결제 › 월별 정산서에서 정산 기준 금액과 수수료, 정산 일정 확인

수수료 인보이스 작성 방법

  • 받는 곳(Bill To)은 NAVER Corp., 청구 금액은 월별 정산서의 수수료와 일치
  • 여러 달의 수수료를 한 장에 청구할 때는 월별로 항목을 나눠 기재
  • 수취 은행 정보는 등록 때 제출한 Registration Form과 동일하게, 법인 서명 또는 직인 포함
  • 해외 파트너사는 세금계산서 발행과 원천징수 대상 아님
